jx_sqlCall

Pointer jx_sqlCall ( Pointer procedureName, Pointer inputParms)

Calls a SQL stored procedure with the passed parameters.

Parameters

  1. Pointer [value, string] — Qualified SQL procedure name
  2. Pointer [value] — noxDB object tree with input parameters

Return Value

Pointer — noxDB object tree with output parameters

Info

The caller of this procedure needs to take care of freeing the resources of the returned noxDB object tree by calling jx_close(node).

jx_sqlCallNode

Boolean jx_sqlCallNode ( Pointer procedureName, Pointer parm01, Pointer parm02, Pointer parm03, Pointer parm04, Pointer parm05, Pointer parm06, Pointer parm07, Pointer parm08, Pointer parm09, Pointer parm10)

Calls a SQL stored procedure with the passed parameters. The passed parameters are either JSON or XML strings or noxDB object trees. Passing object trees to the stored procedure lets you use these object trees directly in the stored procedure. A passed string will be parsed into a new noxDB object tree.

Parameters

  1. Pointer [value, string] — Qualified SQL procedure name
  2. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  3. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  4. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  5. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  6. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  7. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  8. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  9. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  10. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree
  11. Pointer [value, string, nopass] — JSON or XML strings or noxDB object tree

Return Value

Boolean — *on if an error occured else *off

Info

The caller of this procedure needs to take care of freeing the resources of the returned noxDB object tree by calling jx_close(node).

jx_sqlGetMeta

Pointer jx_sqlGetMeta ( Pointer statement)

Returns an object tree (array) with column meta data. The returned array contains one element for each column. This element (object tree) contains the following attributes:

  • name : column name
  • datatype : SQL datatype name (like int, varchar, timestamp)
  • sqltype : SQL datatype id (like 4 for int)
  • size : max. number of characters (not bytes)
  • header : column label

Parameters

  1. Pointer [value, string] — SQL SELECT statement with the columns to be queried

Return Value

Pointer — Object tree (array) with column meta data

Info

The caller of this procedure needs to take care of freeing the resources of the returned noxDB object tree by calling jx_close(node).

jx_sqlSetOptions

void jx_sqlSetOptions ( Pointer options)

This needs to be the first call if any SQL options need to be set. Supported SQL options are:

upperCaseColName

true means that the column names in the result set are in upper case. Default: false.

autoParseContent

true means that any JSON or XML data in columns will be parsed into subobjects in the resulting object. Default: true.

DecimalPoint

The value of this option is used as a decimal point.

sqlNaming

true means that SQL Naming is used and any non qualified tables are searched in the current schema. false means that system naming is used and the tables are searched in the library list.

Parameters

  1. Pointer [value, string, nopass] — Object tree or JSON string containing SQL options or *null to use the default options

jx_sqlStartTransaction

Boolean jx_sqlStartTransaction ( )

Starts a new transaction. If commitment control has not been started yet it will be started now. The transaction will end on either commit or rollback.

Return Value

Boolean — *on if an error occured else *off

Info

Transaction Isolation Level (Scope) will be REPEATABLE READ.

jx_sqlUpsert

Boolean jx_sqlUpsert ( Pointer table, Pointer row, Pointer where)

Executes an UPDATE TABLE where the row is defined as an object tree if the table contains a row matching the passed WHERE clause. If the table does not contain any matching row the passed row will be INSERTed into the table.

Parameters

  1. Pointer [value, string] — SQL table name
  2. Pointer [value, string] — Row data as either object tree or JSON or XML string
  3. Pointer [value, string, nopass] — Input parameter (don't have to pass anything as it is not needed on INSERT)

Return Value

Boolean — *on if an error occured else *off

Info

Depending on the WHERE clause more than one row may be updated by this function.
