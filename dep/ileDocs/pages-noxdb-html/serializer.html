Varchar jx_asJsonText ( Pointer node)

Parameters

  1. Pointer [value] — Node

Return Value

Varchar (32767) — Object tree representation as a JSON string

jx_asJsonTextMem

UnsignedInteger jx_asJsonTextMem ( Pointer node, Pointer buffer, UnsignedInteger bufferSize)

Places the passed object tree as a JSON string into the passed buffer.

Parameters

  1. Pointer [value] — Node
  2. Pointer [value] — Buffer
  3. UnsignedInteger (10) [value, nopass] — Buffer length (in bytes)

Return Value

UnsignedInteger (10) — Length of the serialized JSON string

Info

If no buffer length is passed the procedure will assume the default buffer size which is about 2GB, see MEMMAX defined in memUtil.h.

jx_writeCsvStmf

void jx_writeCsvStmf ( Pointer node, Pointer fileName, Integer ccsid, Boolean trim, Pointer options)

Writes the object tree as a CSV (character seperated values) string to a stream file in the IFS.

The options parameter is a noxDB object tree with following values:

  • delimiter : value separator
  • decPoint : decimal point character
  • headers : true = column headers will be written

Parameters

  1. Pointer [value] — Node
  2. Pointer [value, string] — File name (either a literal or null-terminated in a variable)
  3. Integer (10) [value] — CCSID of the output file
  4. Boolean [value] — *on = output will be trimmed else *off
  5. Pointer [value, string, nopass] — Options

Info

CCSIDs 1200 and 1208 will get a BOM prepended to the actual values.
Any existing file will be overwritten.

jx_writeJsonStmf

void jx_writeJsonStmf ( Pointer node, Pointer fileName, Integer ccsid, Boolean trimOption, Pointer options)

Writes the object tree as a JSON string to a stream file in the IFS.

Parameters

  1. Pointer [value] — Node
  2. Pointer [value, string] — File name (either a literal or null-terminated in a variable)
  3. Integer (10) [value] — CCSID of the output file
  4. Boolean [value, nopass] — *off = output will be pretty printed else *on (default)
  5. Pointer [value, string, nopass] — Object tree node with options (not supported atm)

Info

By default a BOM will be prepended for unicode data. If no BOM is needed then the CCSID should be stated as a negative number, like -1208 for UTF-8.
Any existing file will be overwritten.
The trimming of the output refers only to the formatting / pretty printing of the document. Any leading or trailing spaces in any values will be preserved.

jx_writeXmlStmf

void jx_writeXmlStmf ( Pointer node, Pointer fileName, Integer ccsid, Boolean trim, Pointer options)

Writes the object tree as a XML string to a stream file in the IFS. A XML header including the used encoding will be written at the start of the XML file.

Parameters

  1. Pointer [value] — Node
  2. Pointer [value, string] — File name (either a literal or null-terminated in a variable)
  3. Integer (10) [value] — CCSID of the output file
  4. Boolean [value] — *off = output will be pretty printed else *on (default)
  5. Pointer [value, string, nopass] — Object tree node with options (not supported atm)

Info

Following CCSIDs are supported: 1200, 1208, 819, 1252. Every other CCSID defaults to 1252.
CCSIDs 1200 and 1208 will get a BOM prepended to the actual XML.
Any existing file will be overwritten.
The trimming of the output refers only to the formatting / pretty printing of the document. Any leading or trailing spaces in any values will be preserved.
