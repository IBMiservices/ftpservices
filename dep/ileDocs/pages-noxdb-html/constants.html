Constants

JX_AFTER_SIBLINGNode Copy - Reference location : after sibling
JX_ALLROWSAll rows should be returned.
JX_APPROXIMATE_TOTALROWSResult set format option for returning the approximate number of total rows in the result set object property "totalRows". This option executes faster than JX_TOTALROWS but is not as precise.
JX_ARRAYNode type ARRAY
JX_BEFORE_SIBLINGNode Copy - Reference location : before sibling
JX_BY_CONTEXTNode type BY CONTEXT
JX_CAMEL_CASEResult set format option to return the column names in camel case. "THE_COLUMN_NAME" will be returned as "theColumnName".
JX_COPY_CLONEArray Operation : copy
JX_DELIMITERSDefault delimiters for JSON and XML data strings.
JX_DONTREPLACEMerge Option : Do not replace nodes
JX_EVALNode type EVAL
JX_FIELDSResult set format option for additionally returning meta data about the table columns with the result set in the property "metaData.fields".
JX_FIRST_CHILDNode Copy - Reference location : first child
JX_FORMAT_CDATANode Option Format : XML Serializer CDATA Format
JX_FORMAT_DEFAULTNode Option Format : XML Serializer Default Format
JX_IGNORE_CASEArray Value Lookup : Case insensitive
JX_LAST_CHILDNode Copy - Reference location : last child
JX_LITERALNode type LITERAL
JX_METAResult set format option for additionally returning meta data with the result set in the property "metaData". This option triggers returning the result set to be an object instead of the default array.
JX_MOVE_UNLINKArray Operation : Unlink and move
JX_OBJCOPYNode type OBJECT COPY
JX_OBJECTNode type OBJECT
JX_OBJLINKNode type OBJECT LINK
JX_OBJREPLACENode type OBJECT REPLACE
JX_POINTER_VALUENode type POINTER VALUE
JX_REPLACEMerge Option : Replace existing nodes
JX_ROOTNode type ROOT
JX_ROWARRAYResult set format option for returning the result set as an array with each row contained in a seperate object inside the returned array.
JX_SAME_CASEArray Value Lookup : Case sensitive
JX_SYSTEM_NAMESResult set format option to return system column names instead of sql column names.
JX_TOTALROWSResult set format option for returning the total number of rows returned in the result set object property "totalRows".
JX_UNKNOWNNode type UNKNOWN
JX_UPPERCASEResult set format option for returning the column names in upper case.
JX_USE_LOCALEArray Sort : array nodes comparison using current locale
JX_VALUENode type VALUE
