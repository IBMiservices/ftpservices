jx_dataGen

Pointer jx_dataGen ( Pointer node)

This implementation of a data-gen generator takes a data structure and maps it to a noxDB object tree. The noxDB object tree will be created by this function an does not need to exist.

Parameters

  1. Pointer — noxDB object tree (output parameter)

Return Value

Pointer — Procedure pointer of the data-gen generator function

Info

The noxDB object tree returned by this procedure through the output parameter needs to be freed by calling jx_close(node) by the user of this function.

jx_dataInto

Pointer jx_dataInto ( Pointer node)

This implemenation of a data-into parser takes a noxDB object tree and maps it to a data structure.

Parameters

  1. Pointer [value] — Node to be mapped to a data structure

Return Value

Pointer — Procedure pointer of the data-into parser
