Basics

noxDB is an open source framework that makes it easy to work with XML, JSON and SQL with one single approach - from within RPG.
Node path expression
As noxDB is an object graph you can access its nodes via a node path expression similar to XML XPath. noxDB supports a slash ( / ) or a dot ( . ) as a delimiter for the nodes.

/customer/name is the same expression as customer.name

The current node can be accessed by passing either '' (empty string) or *null to the function.

Array elements can be access by using a bracket syntax like /customer/address[0]/street.

The last element of an array can be retrieved by using the reserved word UBOUND like this /customer/address[UBOUND].

Functions will do nothing if the node to work on is *null or source or destination is *null. If the function should return anything *null is returned.
SQL functions
If the function returns a boolean value indicating success or error in case of an error the function jx_message returns the SQL error message.
CCSID
To make sure that the parsers use the correct delimiters regardless of the CCSID at compile time of the service program always use jx_setDelimiters(JX_DELIMITERS) before using the parser.

jx_arrayAppend

Pointer jx_arrayAppend ( Pointer destination, Pointer source, UnsignedInteger pushMode)

Appends all nodes from one array to another array.

Parameters

  1. Pointer [value] — Destination array (to)
  2. Pointer [value, string] — Source array (from)
  3. UnsignedInteger (5) [value, nopass] — Push operation mode (JX_MOVE_UNLINK (default) or JX_COPY_CLONE)

Return Value

Pointer — Destination array

jx_arrayPush

Pointer jx_arrayPush ( Pointer array, Pointer node, UnsignedInteger pushMode)

Appends the passed node/value to the array. The node can either be an noxDB object tree or a string. If a string is passed and it is a JSON expression (starting with { or [) it will be parsed else the string will be appended to the array as it.

Parameters

  1. Pointer [value] — Array
  2. Pointer [value, string] — Node to be appended to the end of the array
  3. UnsignedInteger (5) [value, nopass] — Push operation mode (JX_MOVE_UNLINK (default) or JX_COPY_CLONE)

Return Value

Pointer — New node added to the end of the array

jx_arraySlice

Pointer jx_arraySlice ( Pointer array, Integer from, Integer to, UnsignedInteger copyMode)

Removes nodes from an array. The node specified on the "to" parameter is included (also removed).

Parameters

  1. Pointer [value, string] — Array or JSON array string
  2. Integer (10) [value] — From index (1-based)
  3. Integer (10) [value] — To index (-1 = all nodes from "from" index to till the end)
  4. UnsignedInteger (5) [value, nopass] — Copy operation mode. JX_MOVE_UNLINK (default) removes the "sliced" nodes from the source array. JX_COPY_CLONE leaves the nodes in the source array and just copies the nodes to the new array.

Return Value

Pointer — New array with the "sliced" nodes

jx_copyValue

Pointer jx_copyValue ( Pointer destNode, Pointer destName, Pointer sourceNode, Pointer sourceName)

Copies the value of a node to an existing node.

If the source node is an object or array (type JX_ARRAY or JX_OBJECT) the object or array will be cloned to the destination value.

If the source node does not exist nothing will be copied and *null is returned.

If the source or destination is relative to the node the node path expression can be used to specify the location.

Parameters

  1. Pointer [value] — Destination node
  2. Pointer [value, string] — Destination node path expression
  3. Pointer [value] — Source node
  4. Pointer [value, string] — Source node path expression

Return Value

Pointer — New node or *null if the operation could not be executed

jx_forEach

Boolean jx_forEach ( jx_iterator iterator)

Iterates through the child nodes of the iterator start node. The entries are either the entries of an array or the keys of an object depending on the start node.

The current value (iterator.this) and some additional information (isFirst, isLast, ...) can be retrieved from the iterator data structure.

The iteration can be interrupted either by leaving the loop or by setting iterator.break to *on.

Parameters

  1. Data Structure jx_iterator — Iterator

Return Value

Boolean — *on if there is another entry , *off if the iteration ended

jx_httpRequest

Pointer jx_httpRequest ( Pointer url, Pointer payload, Pointer options)

Executes an HTTP request. By default it will be a GET request. If a payload has been passed the payload will be serialized to a JSON string and the request will automatically be a POST request. The payload will be passed as unicode to cURL.

The returned JSON object contains the attribute "success" (either true or false) and "reason" (which contains the cURL error output (to stderr) of the request).

Parameters

  1. Pointer [value, string] — URL
  2. Pointer [value, string, nopass] — HTTP request payload (object tree)
  3. Pointer [value, string, nopass] — Extra cURL options

Return Value

Pointer — JSON object

Info

This function uses the curl command.

jx_moveObjectInto

Pointer jx_moveObjectInto ( Pointer destination, Pointer name, Pointer source)

Moves a source object into a destination object. If the source object is no root object it will be unlinked from its current object tree. The source object will be available in the destination object under the passed name.

If no name is passed ('' or *null) then the source object replaces the destination object in its current position in the object tree.

Any existing node with the passed name in the destination object will be replaced by the source object.

Parameters

  1. Pointer [value] — Destination object
  2. Pointer [value, string] — New node name
  3. Pointer [value] — Source object

Return Value

Pointer — Source object

Info

The name parameter is no node path expression! It is the concrete name of the source object in the destination object.

Parses a JSON or XML stream file. The encodings ASCII, UTF8, 1252 and EBCDIC of the current job are supported.

Parameters

  1. Pointer [value, string] — Path to the XML or JSON file (null-terminated)
  2. Pointer [value, string, nopass] — Options are no longer supported (deprecated)

Return Value

Pointer — Pointer to the root node of the noxDB object tree or *null if the file is not readable.

  3. Pointer [value] — Value
